用本地编辑器写作

本文由本地写作编辑器（editor.py）创建，演示“保存即发布”。

怎么用

  1. 本机运行 python editor.py，打开 http://127.0.0.1:8010；
  2. 左侧选模块/条目，或点「＋ 新建」；
  3. 中间输入 Markdown，右侧预览与发布渲染一致；
  4. 点「保存并发布」→ 自动写文件、重建站点、git 提交并推送，约 1 分钟线上更新。

为什么需要本机服务

静态站没有后端，浏览器页面无法直接写入仓库；编辑器在本机起一个小服务，把内容变成 git 提交推送到 GitHub，Actions 与 Pages 自动收尾。
